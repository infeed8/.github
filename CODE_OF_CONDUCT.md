# Code of conduct

Infeed8 repositories are workplaces. Everyone who takes part, whether employee, customer or
contributor, is expected to:

- stay respectful and professional, also when disagreeing
- criticise code and decisions, not people
- welcome questions and give constructive feedback
- keep credentials, confidential information and customer data out of issues, pull requests and commits

Not tolerated: harassment, discrimination, insults, personal attacks, threats, and publishing
other people's private information.

## Reporting

Use **Report content** in the ··· menu of the comment, issue or pull request concerned.
The report goes to the maintainers or to GitHub, not to the public, and is handled confidentially.

## Consequences

Maintainers remove content that breaks this code and may block participants from the
organization, temporarily or permanently.
