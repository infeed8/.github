# Security policy

Please **do not** report security vulnerabilities in public issues, discussions or pull requests.

## Reporting a vulnerability

Report it privately through GitHub: open the affected repository, go to the **Security** tab and
choose **Report a vulnerability**. Only you and the maintainers can see the report.

Please include:

- the affected repository, version or commit
- steps to reproduce, or a proof of concept
- the impact you expect

We will confirm that we received your report and keep you informed until the issue is resolved.
Please give us reasonable time to fix the problem before you disclose it.
